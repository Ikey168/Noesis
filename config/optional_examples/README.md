# Explicit operator examples

Review and replace placeholders before execution. Nothing in this directory runs automatically. The model-download example authorizes only the pinned E5 download under its stated byte ceiling. The court and GitHub examples authorize network reads only when passed to the CLI with matching trusted scopes. Do not put credentials into these files. See `docs/guides/optional-runtime-integrations.md`.

For optional GLiNER2 combined extraction, pass a parsed schema from
`config/extraction_schemas/` as `payload.schema` through the existing source-analysis
operation. German authorities, EU funding, Berlin legal notices and the separate
nine-type English politics benchmark have explicit presets. These are extraction
requests, not validation rules establishing evidence truth. Missing fields remain
explicit. The published DE/EN entity and English relation comparison, setup and
limits are recorded in `docs/development/backlog-execution-2026-09-09.md`; adoption
is deferred and production defaults remain unchanged.
