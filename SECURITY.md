# Security policy

Report vulnerabilities privately with a GitHub private security advisory for
the Noesis repository. Do not publish an issue containing an exploit,
credential, private corpus content, or a bypass of tenancy, source policy,
redaction, provenance, citation, tool, or execution controls.

Include the affected version, minimal synthetic reproduction, impact, and trust
boundary. Maintainers should preserve evidence, assess containment, add a
regression test, and coordinate disclosure after a verified fix is available.

Credentials and recovery material belong in protected runtime custody. Private
sources, production databases, model/provider tokens, and verbatim sensitive
outputs must not be placed in source, fixtures, logs, exports, or issue reports.
