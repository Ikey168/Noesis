# Games evidence (culture.games)

Evidence for the proposed `culture.games` provider of the `culture` bundle
([ADR-007](../../architecture/decisions/ADR-007-culture-bundle.md)) (subdomain
`games`, audit issue #2822, wave 3 tracker #2814; no per-track issue yet).

- [source-audit.md](source-audit.md) - GM01: per-candidate contract for
  Wikidata, the MobyGames API and IGDB; licence, access, how release dates per
  platform and region stay distinct, minimisation and the bounded first
  coverage. Written without network access; terms not re-verified live. Only
  Wikidata survives, `unverified-live`, as "what Wikidata states"; MobyGames and
  IGDB are `not-implemented` because local retention and display are not
  confirmed by their terms.
- Offline evidence: none yet. No fixtures, provider or ingestion module exist.
- Live evidence: none yet.
