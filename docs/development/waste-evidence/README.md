# Waste and circular economy evidence (environment.waste)

Evidence for the Climate and Environment bundle's `environment.waste` provider
(subdomain `waste-circular-economy`, track #2740, wave 2 tracker #2736).

- [source-audit.md](source-audit.md) - WC01: per-source contract, licence,

  network access; terms not re-verified live.

  2098-2099, facility names marked as fixtures), regenerated by
  `tests/unit/waste_fixture_builder.py`: `tests/fixtures/source_packs/environment-waste-*.json`
  (pinned in `packs/climate-environment/source_packs/climate-environment-waste.json`
  1.0.0) and the revision fixtures in `tests/fixtures/waste/`.
- Live evidence: none yet. Until a dated live run exists every source is
  `unverified-live` and offline coverage is never reported as live coverage.
