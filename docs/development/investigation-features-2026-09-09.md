The comparison preserves recorded branch declarations separately from inferred change classifications. It does not run a semantic contradiction detector or declare a winner. Source locations and native revisions remain attached to the structured artifact; unavailable display text is explicit. Export uses the existing report renderer without fabricating a report snapshot or modifying an authored report. Cumulative project spending is clearly distinguished from isolated run billing.

Citation observation cursors are explicitly separate from per-pack ingestion watermarks. Direct source observations can use zero; treating those counters as one global sequence would miss changes. Observation hashes and durable subscription events provide deduplication and recovery. Heuristic source takedown detection does not become a confirmed withdrawal without explicit source lifecycle metadata. Existing subscription read/delivery paths also recheck citation target access.

Template provenance is an additive field in the existing project schema. Three new JSON schemas cover templates, citation alerts and comparisons, and public workflow tests validate their actual outputs. The generated MCP catalog contains the new methods and mutability/scope declarations. Additive tables initialize through write operations; reads do not create schemas.
