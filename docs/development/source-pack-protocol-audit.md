Provider-specific fixtures remain actionable follow-up where required.

## Concrete adapter work

These are implementation requirements, not claims of working runtime support. Schema fixtures must use the native envelopes below rather than normalized Noesis records.

| Source | Required native boundary and fixture |
|---|---|
| World Bank | GET `/v2/country/{country}/indicator/{indicator}?format=json&page=…&per_page=…&date=…`; decode the two-element metadata/data array, persist numeric page, preserve null observations. [Provider documentation](https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures). |
| Eurostat | Append a dataset code to `/statistics/1.0/data/`; decode JSON-stat dimension indexes and sparse `value` cells into observations. Bound dimension expansion; do not invent generic record pagination. [Provider documentation](https://ec.europa.eu/eurostat/web/user-guides/data-browser/api-data-access/api-getting-started/api). |
| FRED | GET `/fred/series/observations` with `series_id`, query `api_key`, `file_type=json`, limit/offset and date window; consume `observations` and count. Vintage/revision operations need their own endpoint mapping. [Provider documentation](https://fred.stlouisfed.org/docs/api/fred/series_observations.html). |
| SEC | GET `/submissions/CIK{ten-digit-cik}.json`; identify the client using User-Agent, not Bearer auth. Zip equal-length recent-filing arrays and follow declared historical files within the same host and run budget. Reject unequal arrays. [SEC access guidance](https://www.sec.gov/about/developer-resources). |
| BBC | Feed XML, not JSON; route to the conditional-feed connector and preserve entry IDs, URLs, validators and unchanged checks. No generic next cursor. |
| GDELT | Native query plus `mode=artlist`, `format=json`, bounded `maxrecords` and time window; map article candidates, not full text. A filled result cap means potentially incomplete discovery, not exhaustive pagination. [Provider documentation](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/). |
| Internet Archive CDX | JSON output is a header row followed by arrays. Map columns by name; distinguish capture timestamp from original publication and retain original URL/digest/status. Resume behavior needs native endpoint fixtures. [Provider documentation](https://github.com/internetarchive/wayback/tree/master/wayback-cdx-server). |
| RDAP | Append the encoded domain; decode one domain object with event records and notices. Bootstrap redirection needs an explicit validated registry-host policy; current same-host policy cannot blindly follow it. |
| Elections Canada | Declared `content.aspx` is an HTML entry point. Select and pin an official election results download, dataset schema and election identity; do not parse this page as JSON records. |
| Bundestag DIP | Select `/drucksache`, `/plenarprotokoll` or the relevant documented resource, map native date filters and API-key authentication, decode `documents` and returned `cursor`. Roll-call capability must be verified separately. [Official OpenAPI](https://search.dip.bundestag.de/api/v1/swagger-ui/). |
| EUR-Lex | The declared help page is not the service endpoint. Implement the documented authenticated SOAP search boundary or a separately declared data-reuse interface; preserve CELEX/version relationships. Generic GET must stay unsupported. |
| arXiv | Reuse `ArxivClient` Atom parsing and structured search, with start/max_results and paced bounded windows, through an explicit runtime bridge. The existing PaperConnector works separately. |
| DataCite | GET `/dois` with native filters and `page[size]`; map `data[].attributes`; begin cursor `1` and consume `links.next` after validating host and parameters. Do not numerically increment the cursor. [Provider pagination](https://support.datacite.org/docs/pagination). |
| Git CPython | Use the existing Git connector's commit/tag acquisition and object identities. A `.git` endpoint is a Git protocol boundary, not JSON search. |
| npm | Append an encoded package name; map version-keyed package metadata, dist-tags and timestamps using the existing registry connector. No generic cursor. [Registry API](https://github.com/npm/registry/blob/main/docs/REGISTRY-API.md). |
| OSV | POST `/v1/query` with package/version or commit; consume `vulns` and `next_page_token`, supplying `page_token` next time. Advisory retrieval is a separate GET operation. [Provider query contract](https://github.com/google/osv.dev/blob/master/docs/api/post-v1-query.md). |
| PyPI | GET `/pypi/{package}/json` or `/pypi/{package}/{version}/json`; map info/releases/files and yanked state through the registry connector. [Provider API](https://docs.pypi.org/api/json/). |
| RFC Editor | Select the RFC number and declared text/XML representation, preserve section anchors and updated-by/obsoletes relationships through the specification connector. Directory root is not a JSON record endpoint. |
| Federal Register | Preserve `results` but add native conditions, page/per_page and next-page handling, document-number identity, and official content acquisition. Top-level results compatibility alone does not prove the operation mapping. [Provider API](https://www.federalregister.gov/developers/documentation/api/v1). |
| Guardian | Implemented after this audit: `/search`, page/page-size, API-key query auth, date windows, `response.results` and currentPage/pages. Shared mapper and fixtures cover the legacy connector and new source pack; live credentials are absent. |

Prioritize bridges to existing arXiv, feed, Git, registry and specification connectors before duplicating their parsers. Then implement native statistical and legislative operations with representative null, empty, malformed and paginated envelopes. Sources marked unsupported remain visibly unsupported in protocol readiness even when an offline normalized fixture passes.

Representative original native-schema fixtures for World Bank, Eurostat, SEC and OSV now exercise the generic adapter and verify it remains unsupported: the envelope/metadata wrapper is not a native record mapping and native pagination is lost. These tests diagnose incompatibility; they do not declare these providers implemented.
